# GYM 벤치마크

각 게임의 공식 Steam 소개에서 확인한 기능과 GYM에 적용한 설계를 구분했습니다. 보상 수치와 지급 간격은 GYM용으로 설계한 값입니다.

| 레퍼런스 | 공식 소개에서 확인한 기능 | GYM 적용 |
| --- | --- | --- |
| [Rhythm Doctor](https://store.steampowered.com/app/774181/Rhythm_Doctor/) | 단일 버튼으로 박자를 맞추는 조작, 단계별 리듬 학습 | 드래그를 정확하게 반전하면 PERFECT 판정과 GP 1.5배. 단순 왕복에 숙련 보상 추가 |
| [Keep on Mining!](https://store.steampowered.com/app/3769130/Keep_on_Mining/) | 영구 스킬 트리, 장비 강화, 레벨업 시 특성 카드 3개 중 선택 | 영구 패시브 15종과 행동에 영향을 주는 강화. 카드 선택은 이번 버전에 미적용 |
| [To The Core](https://store.steampowered.com/app/1988550/To_The_Core/) | 제한된 연료로 자원 채집, 연료와 작업 능력 강화, 자원별 누적 채집에 따른 숙련 보너스 | 하루 체력과 영구 성장의 반복 구조. 부위별 누적 GP를 신체 성장에 반영하고 변화를 더 잘 보이도록 개선 |
| [Nodebuster](https://store.steampowered.com/app/3107330/Nodebuster/) | 자원을 모아 스킬 트리를 탐색하고 능력 강화 | 기본 첫 운동 보상 8 GP와 첫 강화 비용 8 GP를 맞춰 첫 구매를 빠르게 경험 |
| [BALL x PIT](https://store.steampowered.com/app/2062430/BALL_x_PIT/) | 능력 결합과 시너지, 영구 건물 보너스, 플레이 방식을 바꾸는 특성 | PERFECT 체력 회복, 운동 전환 보너스, 펌프 연장을 조합하는 패시브 |
| [Digseum](https://store.steampowered.com/app/3361470/Digseum/) | 발굴·전시·수익·강화의 순환, 여러 발굴지와 수집품, 짧은 완결형 성장 | 누적 GP에 따른 다섯 랭크와 일회 보상으로 중장기 목표 제공 |

## 적용한 보상 구조

| 간격 | 적용 내용 |
| --- | --- |
| 매 반복 | 기본 8 GP. 정확한 반전은 PERFECT로 1.5배 보상 |
| 5회 누적 | 다음 5회는 체력을 소모하지 않고 GP를 2배 받는 펌프 상태 |
| 첫 구매 | 첫 강화 비용 8 GP. 기본 보상만 받아도 첫 운동 후 구매 가능 |
| 하루 | 기본 체력 40, 반복당 기본 소모 8. 강화 전 일반 반복 5회 분량 |
| 영구 성장 | 누적 GP 60 / 180 / 420 / 900 / 1,800에서 랭크 상승 및 일회 GP 지급 |
| 신체 변화 | 해당 부위 운동으로 누적 획득한 GP에 따라 신체 성장. 패시브 구매로 GP를 소비해도 몸의 성장은 유지 |

## 플레이를 바꾸는 패시브

- PERFECT 판정 시 체력 2 회복(펌프 중 제외).
- 운동 전환 후 첫 반복의 GP 50% 추가.
- 펌프 상태를 2회 연장.

기존 수치 강화와 함께 총 15종으로 구성했습니다. 기존 v1 저장은 v2 형식으로 이전하여 이어서 플레이할 수 있습니다.

## 설계 의도

일반 반복, 정확한 조작, 펌프, 강화 구매, 랭크 상승이 서로 다른 간격으로 보상을 제공합니다. 특히 초기 보상 간격을 줄여 신체 성장과 다음 강화의 차이를 첫 플레이에서 경험하도록 조정했습니다.
