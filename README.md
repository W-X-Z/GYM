# GYM CLUB — PUMP EDITION

기구를 마우스로 들어 올렸다 내리며 근육을 키우는 3D 인크리멘탈 게임입니다. 정확한 동작으로 추가 보상을 받고, 다섯 번의 운동을 무료 펌프 운동으로 이어가며 패시브와 몸을 성장시킵니다.

## 바로 실행

저장소의 **[gym-mvp.html](gym-mvp.html)**을 다운로드해 Chrome 또는 Edge에서 여세요. 외부 CDN, 설치, 로그인 없이 실행됩니다. 모바일에서는 HTML 파일을 브라우저로 열거나 정적 웹 서버에 올려서 사용하세요.

개발 실행은 Node.js 22 이상에서:

```bash
npm run dev
# http://localhost:3000
npm test
npm run build
```

별도 패키지 설치가 필요 없습니다. Three.js r160을 라이선스와 함께 `vendor`에 포함했습니다.

## 조작

1. 헬스장의 기구 또는 운동 목록을 선택합니다.
2. 주황색 손잡이를 위로 끝까지 드래그하고 아래로 되돌립니다. 터치도 같은 방식입니다.
3. 위쪽 표시 지점에서 과하게 당기지 않고 바로 되돌리면 **PERFECT**로 GP를 1.5배 받습니다.
4. 일반 운동을 5회 완료하면 **PUMP MODE**가 시작됩니다. 다음 5회는 체력이 들지 않고 GP가 2배입니다. PERFECT와 중첩됩니다.
5. 패시브 트리에서 GP로 강화하고, 하루를 마무리한 뒤 다음 날을 시작하면 체력이 회복됩니다.

손을 놓은 미완료 동작은 취소됩니다. 위/아래 방향키로도 운동할 수 있으며, Esc로 헬스장에 돌아갑니다. 도움말에서 저장 초기화를 선택한 뒤 재확인할 수 있습니다.

## 성장과 보상

| 항목 | 기본 규칙 |
| --- | --- |
| 운동 | 벤치프레스는 가슴, 덤벨 컬은 팔, 스쿼트는 하체 성장 |
| 체력 | 하루 40, 일반 운동 1회당 8 소모 |
| GP | 일반 운동 8 GP, PERFECT 1.5배, 펌프 2배 |
| 첫 강화 | 8 GP부터 구매 가능. 첫 일반 운동 한 번으로 구매 가능 |
| 펌프 | 일반 운동 5회 후 무료 운동 5회. 종료 후 다시 5회를 모아 재발동 |
| 전신 보너스 | 하루에 세 부위를 모두 운동하면 사용 가능한 GP 20 추가, 하루 한 번 |
| 신체 성장 | 해당 부위 운동으로 누적 획득한 GP에 비례. GP를 소비해도 몸은 작아지지 않음 |
| 랭크 | 누적 근성장 60 / 180 / 420 / 900 / 1,800 GP에 도달하면 랭크 상승과 일회 GP 보상 |

랭크와 전신 보너스는 구매용 GP만 지급하며 특정 부위의 근성장을 부풀리지 않습니다. 마지막 랭크인 **헬스장 전설** 이후에도 남은 강화와 운동을 계속할 수 있습니다.

패시브는 총 **15종**입니다. 체력, 기본 보상, 부위 집중, 체력 효율, 판정 여유, 증량, 전신 루틴, 전체 보상 강화에 다음 세 가지 효과를 추가했습니다.

- **완벽한 호흡:** 일반 운동의 PERFECT 판정 시 체력 2 회복. 펌프 중에는 회복하지 않습니다.
- **슈퍼세트:** 운동을 바꾼 직후 첫 반복의 보상 1.5배.
- **펌핑 중독:** 이후 발동하는 펌프에 무료 운동 2회 추가.

## 화면과 저장

- 둥근 캐릭터와 3D 헬스장, 세 운동의 자세 및 기구 움직임
- 초기부터 알아볼 수 있는 부위별 근성장, 랭크에 따른 헤어밴드 색 변화
- GP 숫자, PERFECT 판정, 충격 파티클, 원형 효과, 펌프 오라와 효과음
- 펌프 잔여 횟수, 다음 랭크 진행도, 하루 성장 결과
- 소리 켜기/끄기, 모바일 반응형 UI, 움직임 줄이기 설정을 반영한 카메라 효과
- 동일 브라우저의 `localStorage` 자동 저장. 기존 v1 저장을 v2로 이전하여 GP, 부위 성장, 강화와 날짜 유지

신체는 성장할수록 증가 폭이 완만해져 기구를 가릴 만큼 무한히 커지지 않습니다. 저장은 브라우저와 주소별로 독립적이며 클라우드 동기화는 없습니다.

## 렌더링과 구성

WebGL을 사용할 수 없으면 Canvas 2D 기반 3D 호환 렌더러를 사용합니다. 호환 모드에서는 배경과 깊이 정보를 캐시하고 캐릭터, 기구, 효과를 갱신합니다. 해상도와 파티클 수를 조절하며 이동 및 카메라 전환을 즉시 처리해 연산량을 줄입니다.

```text
index.html                 화면 구조
style.css                  데스크톱 / 모바일 UI
src/game.js                보상, 펌프, 랭크, 강화, 성장, 저장 이전
src/scene.js               3D 공간, 캐릭터, 기구, 포즈, 효과, 카메라
src/software-renderer.js   배경 캐시를 사용하는 WebGL 호환 렌더러
src/main.js                입력 판정, UI, 사운드, 저장 연결
tests/game.test.mjs        핵심 게임 규칙 회귀 테스트
scripts/build.mjs          단일 HTML 빌드
scripts/serve.mjs          개발용 정적 서버
docs/BENCHMARKS.md         레퍼런스와 실제 적용 내용
vendor/three.module.js     Three.js r160, MIT
vendor/THREE-LICENSE.txt    Third-party license
gym-mvp.html               다운로드용 실행본
```

## 검증

핵심 로직 테스트 **19개 통과**: 기본 5회와 무료 펌프 5회, 보상 중첩, 체력 회복의 유한성, 운동 전환 보너스, 강화 조건과 상한, 부분·순간 동작 차단, 부위별 성장, 일회 랭크 보상, 펌프 저장 복원 및 v1 저장 이전을 포함합니다.

브라우저에서 실제 드래그로 세 운동, PERFECT, 체력 0에서 무료 운동 5회, 보상 중첩, 전신 보너스, 강화 구매, 저장 복구, 다음 날 회복과 등급 달성을 확인했습니다. 다운로드용 단일 HTML에서도 운동과 저장을 확인했고, 390px 모바일 화면에서 기구 선택과 왕복 운동을 확인했습니다. 테스트 브라우저의 WebGL이 비활성화되어 호환 렌더러로 검증했으며, GPU WebGL 경로의 실기기 검증은 포함하지 않습니다.

설계 참고 자료와 실제 반영 범위는 **[벤치마크 문서](docs/BENCHMARKS.md)**에 정리했습니다. 캐릭터와 운동기구는 코드로 제작한 기하 모델이며 Gang Beasts의 모델이나 에셋은 사용하지 않습니다.
