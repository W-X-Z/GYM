# GYM CLUB — 작은 헬스장

마우스로 기구를 들어 올렸다 내리며 몸을 키우는 3D 인크리멘탈 게임 MVP입니다.

## 바로 실행

저장소의 **gym-mvp.html**을 다운로드해 Chrome 또는 Edge에서 여세요. 외부 CDN, 설치, 로그인 없이 실행됩니다. 모바일에서는 HTML 파일을 브라우저로 열거나 정적 웹 서버에 올려서 사용하세요.

개발 실행은 Node.js 22 이상에서:

```bash
npm run dev
# http://localhost:3000
npm test
npm run build
```

런타임 및 빌드 패키지 설치가 필요 없습니다. Three.js r160을 라이선스와 함께 vendor에 포함했습니다.

## 조작

1. 헬스장의 기구 또는 운동 목록을 클릭합니다.
2. 주황색 손잡이를 위로 끝까지 드래그한 다음 아래로 되돌립니다. 터치도 같은 방식입니다.
3. 완전한 왕복 동작마다 해당 부위 근성장 포인트를 얻습니다. 손을 놓은 미완료 동작은 취소됩니다.
4. 패시브 트리에서 포인트로 강화합니다.
5. 하루 마무리 후 다음 날을 시작하면 체력이 회복됩니다.

접근성 보조 조작: 운동 중 위/아래 방향키, Esc로 헬스장 복귀. 도움말에서 저장 초기화를 선택한 뒤 재확인할 수 있습니다.

## 구현 범위

- 3D 헬스장, 둥근 캐릭터, 운동별 근육 성장과 포즈
- 벤치프레스(가슴), 덤벨 컬(팔), 스쿼트(하체)
- 기구 선택 시 이동 및 운동 카메라 전환
- 포인터 캡처를 이용한 마우스·터치 왕복 운동
- 부분 동작, 너무 빠른 동작, 체력 부족 상태의 보상 방지
- 초기 체력 24 / 1회 비용 10 / 기본 보상 4 GP
- 12개 패시브 노드, 선행 조건, 다단계 강화 및 증량
- 부위별 누적 GP와 사용 가능 GP의 분리: 소비해도 신체 성장은 유지
- 하루 결과, 회복, 동일 브라우저 localStorage 자동 저장
- 소리 켜기/끄기, 모바일 반응형 UI
- WebGL 미지원 환경에서는 동일한 3D 장면을 Canvas 2D 깊이 버퍼로 렌더링

신체 성장 곡선은 과도한 메시 겹침을 줄이기 위해 완만하게 포화됩니다. GP는 계속 쌓이지만 몸이 무한히 커지지는 않습니다. 저장은 브라우저/주소별로 독립적이며 클라우드 동기화는 없습니다.

## 구성

```text
index.html                 화면 구조
style.css                  데스크톱 / 모바일 UI
src/game.js                보상, 체력, 성장, 강화, 저장 데이터 검증
src/scene.js               3D 공간, 캐릭터, 기구, 포즈, 카메라
src/software-renderer.js   WebGL 미지원 환경용 3D 호환 렌더러
src/main.js                입력, UI, 사운드, 저장 연결
scripts/build.mjs          외부 의존성 없는 단일 HTML 빌드
scripts/serve.mjs          개발용 정적 서버
vendor/three.module.js     Three.js r160, MIT
vendor/THREE-LICENSE.txt    Third-party license
 tests/game.test.mjs       핵심 성장 규칙 회귀 테스트
 gym-mvp.html              다운로드용 완성 실행본
```

## 검증

- Node.js 테스트 8개 통과: 초기 2회 운동, 포인트 소비 후 성장 유지, 강화 조건·상한, 하루 회복, 균형 루틴, 왕복 판정, 부위별 성장, 저장 복구
- 브라우저에서 세 운동 모두 실제 마우스 드래그로 1회 및 해당 부위 +4 GP 확인
- 포인트로 체력 강화 후 새로고침: 강화 상태와 부위별 누적 GP 유지 확인
- 체력 소진 결과 화면 및 다음 날 34/34 회복 확인
- 390px 모바일 레이아웃 확인
- 테스트 브라우저의 WebGL이 비활성화되어 브라우저 실조작 검증은 호환 렌더러에서 수행. WebGL 경로는 별도 GPU 브라우저 확인 필요

캐릭터와 운동기구는 코드로 제작한 독자적인 기하 모델입니다. Gang Beasts의 모델이나 에셋을 사용하지 않습니다.
